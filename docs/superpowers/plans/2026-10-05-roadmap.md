## 里程碑 1:后端基础(SRS P0 地基)

目标:后端连接真实 MySQL 返回 JSON,测试全绿。

1. 数据库准备:创建 `sakiblog` + `sakiblog_test` 库和专用用户;`backend/.env` 写 DSN(凭据不入库,提交 `backend/.env.example`)
2. `backend/app/config.py`:pydantic-settings 读 .env
3. `backend/app/database.py`:同步 engine + `get_session` yield 依赖
4. `backend/app/models.py`:一次建全 5 张表 admin/category/tag/article/article_tag(SRS §4;utf8mb4、ENUM('draft','published','withdrawn')、LONGTEXT 正文、(status, published_at) 复合索引、article_tag 用 Core 表 + CASCADE),后续管理端免迁移
5. 公开读接口 + CORS(允许 5173/4173):`GET /api/health`、`GET /api/posts?page=&page_size=`(仅 published、新→旧、含总数)、`GET /api/posts/{id}`(非 published 返回 404,FR-ARTICLE-008)
6. `create_all` 启动引导(AUTO_CREATE_TABLES 开关);重置 = DROP/CREATE DATABASE 一条 SQL,不引入 Alembic
7. 测试基线:pytest + httpx 连 `sakiblog_test`(不用 SQLite:SRS schema 依赖 ENUM/LONGTEXT,SQLite 会给出虚假信心)

验收:`uv run uvicorn app.main:app` 后 `/api/posts` 返回 JSON;pytest 全绿;ruff 无报错。
